# カニギター｜弦であそぼう

カニギターの弦をタップしたり、なでたりして演奏する、小さな Web 楽器です。HTML / CSS / JavaScript と Web Audio API で動きます。

- [公開中のアプリ](https://kani-guitar-strings.arikuiroom.chatgpt.site)
- [ソースコード](https://github.com/arikuiroom/CrabGuitarKA23M)

## できること

- 6 本の弦を直接タップ・ストローク。標準の音は低い方から E2 / A2 / D3 / G3 / B3 / E4
- 「そのまま」/ C / G / Am / Em を選択。デスクトップでは補助弦パネルとキー 1〜6 でも演奏
- 5 色と連動する音色：赤＝澄んだ響き、ミント＝ファンク、黒＝メタル、焦茶＝ナイロン、赤茶＝ウクレレ風
- 同じ弦の弾き直しでは、新しい音をすぐ鳴らし、前の音を 20ms で滑らかに消音。他の弦と、すでに広がった部屋の残響は自然に残る
- ヘッド寄りの短いタップでハーモニクス。焦茶は短い「ポクッ」という音、赤茶は通常音
- 黒いアームを動かして音程を変化。大きなハサミを押さえて消音（ハサミの目印は非表示）
- 音の減衰に合わせて、一つの大きなハサミと四本の小さな足の動きも小さくなる
- スマートフォンの縦・横画面、セーフエリア、ホーム画面から開く表示に対応。演奏中のページスクロールを抑制

赤茶では 190Hz 未満の音を 1 オクターブ上げます。現在の操作には速度によるカッティング切り替えはなく、速くなでても通常のストロークです。

音はページ内で合成しています。実際のギターの録音サンプル、録音機能、マイク入力、解析用トラッキングは使っていません。

## ローカルで起動

Node.js 20 以上と npm を用意します。外部の依存パッケージはありません。

```sh
git clone https://github.com/arikuiroom/CrabGuitarKA23M.git
cd CrabGuitarKA23M
npm install
npm test
npm run dev
```

[http://127.0.0.1:8080](http://127.0.0.1:8080) を開き、弦を一度タップしてください。`npm install` は依存関係がない現在の構成では省略できます。開発サーバーは `src/` と `public/` の変更をビルドし直します。画面は手動で再読み込みしてください。

```sh
npm run build    # 公開用ファイルを dist/ に生成
npm run preview  # 生成済みの dist/ を同じローカル URL で確認
```

`dist/` は生成物です。変更は `src/` または `public/` に加えてください。GitHub へのソース更新だけでは、公開中のアプリは更新されません。GitHub Pages はこの構成では有効化していません。

## 音が出ないとき

1. 弦を一度タップし、ブラウザの音声再生を開始する
2. アプリのミュートと音量、端末の音量、出力先を確認する
3. iPhone は消音モードを OFF にする

iPhone では、消音モードを OFF にして内蔵スピーカーで鳴ることを確認済みです。実機の同時タッチ、Safari とホーム画面表示の違い、長時間演奏は、更新時にも確認してください。ホーム画面用の設定はありますが、オフライン動作を保証する Service Worker はありません。
