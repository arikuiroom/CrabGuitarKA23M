Browser checks

Run npm run dev, open a fixture, and click its Run button. Keep the tab in the foreground. Some fixtures make sound; lower your volume first.

These are manual browser fixtures, not part of npm test. Synthetic pointer tests do not replace physical multi-touch or iPhone/Safari testing. OfflineAudioContext tests verify native rendering, not device output latency.
